# 慧动科技 FlowSpark 使用手册

## 1. 先了解当前版本

网站提供可以实际操作的演示空间，适合展示、验证教学流程。首页会介绍山西慧动科技与AI学习探索理念，页面支持电脑与手机；如果设备设置了“减少动态效果”，动画会自动降低。

**演示模式不等于正式教学服务。** 演示数据、代码草稿与收藏保存在当前浏览器。演示登录状态在刷新后需要重新选择，数据仍会保留；不同电脑、不同浏览器及隐私窗口不共享数据。清除网站数据会丢失演示作业与提交。不要在演示区存放真实学生个人信息、成绩或敏感代码。

## 2. 正式账号与机构管理

账号由机构统一创建。用机构管理员提供的机构代码、用户名和临时密码登录，首次登录先修改密码。以后在任何设备登录同一账号，都能查询服务器保存的作业、提交及批阅记录；未提交草稿和收藏仍是本地数据。忘记密码请联系管理员，不使用内部登录标识接收重置邮件。

平台管理员先添加“玛酷机器人（迎新校区）”及其机构管理员，另外两家确认名称后添加。机构管理员在“机构与账号”按每批最多20人的三列清单创建师生账号，立即下载临时密码CSV并私下分发，不上传GitHub。停用操作阻止后续私有数据访问。具体步骤见 [免费部署](free-deployment.md)。

## 3. 学生体验

1. 点击“进入学习空间”，选择“我是学生”。
2. 在“竞赛作业”查看示例任务，支持按标题或算法标签搜索。
3. 演示班级邀请码是 `SPARK2026`。正式版输入老师提供的12位邀请码后才会看到对应班级任务。
4. 选择“开始挑战”，阅读题目描述、输入输出、约束与样例。
5. 在编辑器选择 C++17、Python 3 或 Java 17，编写代码。Tab插入四个空格，草稿自动保存在当前浏览器；不同账号、题目和语言使用不同草稿键。
6. 点击“提交作业”，随后在“我的提交记录”查看提交时间、状态、老师的分数与反馈。系统允许在截止时间前多次提交，每次都是独立记录。
7. **当前不执行代码，不自动判AC/WA。** 请在自己的编程环境中运行样例；本平台把提交交给老师人工批阅。

## 3. 教师体验

1. 退出学生体验，再选择“我是老师”。这是体验切换，不能用来证明正式账号权限。
2. 打开“教师工作台”，点击“创建班级”。创建后可复制邀请码。
3. 点击“发布作业”，填写题目、班级、难度、截止时间、题意与约束、输入输出说明、样例及标签。当前发布流程直接发布，学生可以查看。
4. 学生提交后，进入“查看与批阅”，阅读提交的原始代码。
5. 输入0–100分及学习反馈，保存批阅结果。学生重新进入作业即可查看。
6. 教师可“添加资源”，填写课程名称、来源、类型、官网链接与简介。只添加公开或已获授权的内容。

正式模式里教师身份由机构管理员通过受保护的管理功能授予，学生不能通过注册界面、浏览器参数或修改前端状态获得教师权限。老师只能查看自己班级的作业与提交，不能改写学生已提交的代码。

## 4. 学习助手

- 免费首期（含正式账号）默认使用“离线学习提示”，通过本地规则针对前缀和、二分、BFS、复杂度和边界问题给出固定方向的建议，**不是联网AI，也不理解任意对话**。
- 正式版接入AI后，用户登录并选择关联题目，输入问题后通过服务端代理调用模型。默认每个账号每天最多20次请求，按UTC日重置，失败请求也可能计入次数。
- 推荐提问方式：“我尝试了什么”“具体在哪个输入出错”“我认为复杂度是多少”。不要提交身份证、手机号或其他敏感信息。
- AI可能出错；它不会替代老师，也不应声称实际执行了学生代码。

## 5. 学习资源

支持“全部／视频／课件”筛选，或搜索学校和课程关键词。MIT、Harvard、Stanford及OI Wiki入口指向官方站点。点击后在新标签打开；课程语言和官网访问条件由原网站决定。本站与资源方没有声明合作关系，不托管未经授权的视频。收藏按钮的记录仅存于当前浏览器，暂未提供跨设备收藏同步。

## 6. 正式账号与密码

管理员完成后端配置后，登录窗口显示邮箱登录与注册入口，演示身份选择不再展示。

- 学生可用邮箱注册，按邮件完成确认；新账号只会成为学生。
- 正式教师先注册学生账号，再由管理员核验后授予教师身份。
- 忘记密码请联系管理员，通过Supabase后台发送重置邮件；当前前端未提供自助密码重置页面。
- 管理员处理数据导出或删除请求；本版本未提供用户自行删除云端账号的入口。

## 7. 常见问题

**换电脑看不到演示数据？** 属于预期行为；需要接入数据库才能跨设备同步。

**提交后没有AC？** 当前采用老师人工批阅，未接入编译判题机。

**AI没有真正回复？** 演示版只有本地提示；正式版需检查函数部署、服务端密钥、请求来源与账户配额。

**打不开课程？** 课程可能需要官网登录、区域网络条件或已经更换网址；教师可添加新的官方资源。

**正式账号看不到作业？** 检查是否已加入班级、老师是否发布作业，以及当前账号身份是否正确。
