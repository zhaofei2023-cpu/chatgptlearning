# 慧动科技 FlowSpark：资源、竞赛与名校信息使用手册

## 一、这次增加了什么

- **资源中心**：本地视频、课件、知识地图、学习文档；主题命名、改名、素材归类、搜索与类型筛选；草稿、发布、撤回和删除。
- **竞赛活动**：活动简介、参赛对象和要求、报名截止、开赛与结束时间、题目与样例、学生报名和代码提交、管理员人工评阅；按周或月复制下一期草稿。
- **名校探索**：编辑学校名称、内容分类、标题、摘要、正文和官方来源链接，保存草稿或发布。
- **页面**：深蓝科技风头图、清晰卡片、略大的字体，以及文字与背景对比更明显的按钮；兼容电脑、平板和手机。

新页面部署不等于数据库已升级。先完成下面的数据库升级，再使用真实账号上传与发布。

## 三、管理员的内容发布范围

| 角色       | 可以管理                       | 可以学习                                   |
| ---------- | ------------------------------ | ------------------------------------------ |
| 平台管理员 | 全平台及各机构内容             | 全部管理范围                               |
| 机构管理员 | 仅本机构内容                   | 全平台已发布内容和本机构内容               |
| 教师       | 不上传或发布这三个新模块的内容 | 全平台及本机构已发布内容                   |
| 学生       | 不上传或发布                   | 全平台及本机构已发布内容，并按规则报名参赛 |

平台管理员新建内容时选择“全平台师生”或具体机构。机构管理员只能选择本机构。已有内容不能转移机构范围；请在目标范围另建。主题与素材必须属于同一范围。

“机构与账号”页顶部有三个内容管理快捷入口；也可直接通过网站导航进入。

## 四、资源中心：先主题，再素材，最后发布

### 1. 新建或修改主题

进入 **学习资源 → 进入资源管理**，点击“主题导航”右侧 **＋**，填写范围、主题名称和简介。例如“C++基础”“算法竞赛备赛”“AI学习探索”。

主题名完全由管理员定义。主题列表中的编辑按钮可以改名或修改简介。主题只是分类，不会自动发布其中的草稿。

### 2. 添加素材

点 **上传素材**，填写名称、主题、简介和素材类型，再选择：

- **上传本地文件**：视频、PDF、Office文档、图片或纯文本。
- **HTTPS学习链接**：官方课程、外部知识库等。
- **在线正文 / 知识路径**：直接写入文字；知识地图类型会按行显示为学习节点。

本地知识地图建议使用 PNG、JPG、WebP 或 PDF，图的布局和文字保留在文件中。在线知识路径是顺序节点，不是自动生成的复杂思维导图。

选“草稿”仅管理员可见；核对后选“已发布”，点击 **保存素材**。上传过程中不要关闭窗口。视频可在平台内播放，图片可查看，PDF使用浏览器阅读器；PPT/PPTX、DOC/DOCX请下载后在WPS或Office打开，平台不做格式转码。

### 3. 上传限制与免费额度

单文件上限 **40MB**。视频支持 MP4、WebM；推荐兼容浏览器的 H.264/AAC MP4。较大的视频请先压缩、拆分，或用合法的 HTTPS 外链。`.mov`、HTML、SVG、可执行文件和压缩包不在本次上传白名单中。

文件保存在你自己的 Supabase 私有存储，不放入公开 GitHub 仓库。免费套餐并非无限容量；存储总量、流量、调用次数及休眠规则以项目 **Usage** 和供应商当时的免费政策为准。本代码不会自动购买套餐或启用收费转码/AI服务。

上传失败时，新素材仍是草稿，不会伪装成已发布。编辑失败草稿可继续上传；未完成文件上传的素材不能发布。替换文件会尝试清理旧文件，若清理失败可由平台负责人到 Storage 核查，避免删除仍被素材引用的文件。

### 4. 归类、撤回与清理

在素材卡片点编辑，可改名称、简介、主题、来源和文件。在管理视图可撤回为草稿，或者删除素材及其文件。**删除不可恢复**，操作前核对名称并做好备份。

撤回会限制后续访问，但已下载的文件无法远程收回；已生成的私有签名链接最长仍可使用1小时，直到过期。请勿分享包含令牌的文件链接。视频链接过期或浏览器不支持编码时，重新打开内容，或下载后观看。

## 五、竞赛：建立活动 → 添加题目 → 发布

1. 管理员进入 **竞赛活动 → 创建竞赛活动**。
2. 填写标题、简介、发布范围、参赛对象、规则、报名截止和起止时间。所有新竞赛表单明确使用 **北京时间 UTC+8**。
3. 保存为草稿，在“活动详情与题目”中添加题目：题意、输入输出、样例、满分和题目序号。
4. 至少添加一道题，再点 **发布竞赛活动**。开赛前仍可编辑；开赛后题目、赛程、报名截止和规则锁定，必要时可以取消活动。
5. 学生在截止前报名；开赛后刷新活动，可查看题目并在比赛结束前提交代码。教师开赛后可阅读题目，但不能以学生身份报名或提交。
6. 管理员在活动详情的 **报名与人工评阅** 中查看代码、填写分数与评语。学生可以查看自己的成绩与反馈，不能读取其他学生代码或修改分数。

新题在开赛前仅管理员可见；比赛进行中仅已报名学生和所属范围教师可阅读。比赛结束后，所属范围师生可阅读题目作为学习资料。报名资格中的年级、水平等自由文本条件由主办方核验，不会自动检查。

当前提交 **不自动编译运行，不自动判定AC/WA，不提供自动排名**。代码在网页中作为文本查看，由管理员人工评阅。未提交的竞赛代码没有自动草稿保存，关闭前请自行保存。

### 定期举办

活动可选择每周或每月。点 **复制下一期** 会生成新的草稿并复制题目；开始时间按周/月后移，保持比赛时长和报名提前量。月底会采用目标月份的最后有效日期。管理员必须核对日期、活动名称、规则和题目，再发布。

这不是后台自动无限创建活动，也不是未经审核自动发布。已发布活动会按数据库时间自动限制题目可见性和提交窗口，无需浏览器一直开着。

## 六、名校信息：核对来源后发布

进入 **名校探索 → 新建名校信息**，填写学校、分类、标题、摘要、正文和官方来源。可自行使用“学校介绍”“课程动态”“学习指南”等分类名称。

保存为草稿后可继续编辑；发布后，师生可筛选、搜索和阅读详情。管理视图可撤回。学校信息应引用可靠官方来源，不虚构资质、排名、合作关系或录取承诺。系统提供官方公开课入口，但不代表与学校存在合作。

## 七、上线验收

- 管理员创建一个本机构主题并上传小视频、PDF和知识地图，核对名称、归类与预览。
- 学生和教师看不到草稿；本机构已发布资料可访问，另一家机构的私有资料不可访问。
- 撤回或删除测试素材后，新的访问请求被限制，已下载文件不受远程控制。
- 创建未来开赛活动，添加题目、发布；学生开赛前看不到题目，截止后不能报名，未报名不能提交。
- 比赛时间内提交一份测试代码，管理员评阅；学生换设备登录后能看到自己的反馈。
- 复制下一期仅得到草稿；名校信息可编辑、发布和撤回。

本地已进行数据库RLS及浏览器测试；真实 Supabase Storage/网络/账号仍需要上述项目内验收。备份时既要备份数据库，也要备份上传文件，两者不能互相替代。
