# 免费统计与手动学情分析

管理员进入“学情报告”，选择学生和近7、14、30或90天。

1. 点击“生成并保存统计报告”：即时生成作业提交、教师评分及题目标签统计，不调用AI，也不产生AI API费用。
2. 根据需要编辑“报告要求”，可保存为自己的默认模板。点击“准备匿名分析资料”，检查并编辑预览，下载Markdown文件。
3. 打开自己的ChatGPT，将文件上传或粘贴内容。可以继续对话，提出结构、语气、家长摘要和训练计划等要求。此过程使用你现有ChatGPT账户的额度和功能，ChatGPT订阅与API计费彼此独立。
4. 将最终报告粘贴回网站，或读取TXT/Markdown文件（200KB以内、最多40000字）。确认页面显示的学生与时间范围后，点击“保存导入报告”。报告按学生归档，可下载、打印或另存PDF。

导出默认不包含代码，使用“学生A”代号，并替换系统已知姓名、账号、邮箱及大陆手机号。需要静态代码分析时可勾选“附带最新代码”。脱敏无法保证识别所有自由文本中的隐私，请在上传前检查预览，尤其是注释、教师反馈与题目文本。网站不会自动把资料发送给ChatGPT。

统计按每题最新提交时间筛选，重复提交只保留最新版本，无法还原旧版本学习轨迹；累计次数不是本期次数。当前免费统计覆盖日常作业，不含竞赛。没有评分时不生成成绩均值。提交量和知识标签不代表掌握程度，也不证明独立完成。手动导入的AI报告需教师核实，导入时间不代表AI分析时使用了同期数据。

## 部署兼容性

沿用第四版study_reports、study_report_templates表与现有机构权限，无需新增SQL或部署AI函数。报告仅管理员可访问，保存仍由Supabase行级权限校验。演示模式只保存在当前浏览器。

旧study-report函数不再由本页面调用。如果此前配置过AI_ENABLED=true，建议在Supabase Edge Functions的Secrets中改为false，禁用旧API入口；这一设置不影响新的免费流程。历史报告仍可查看。旧AI接入文档仅作为可选方案保留。
