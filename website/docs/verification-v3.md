# 第三版验证与交付范围

2026-11-14，Node.js 24、系统Chromium、本地PostgreSQL（PGlite）。测试不会创建真实师生账号或上传真实教学资料。

## 数据库验证

在隔离数据库执行 schema.sql、002 和新增003迁移，模拟 Supabase Auth 与 Storage 元数据表，使用真实 PostgreSQL RLS 检查：

- 机构管理员不能发布全平台或其他机构内容，学生/教师不能管理新模块。
- 草稿对师生不可见；主题与素材范围匹配，不能改写所属机构或创建者。
- 私有桶、40MiB限制和类型白名单；文件路径与素材关联，跨机构上传/读取被拒绝，未上传完成不能发布。
- 报名截止、开赛前题目保密、已报名学生的提交窗口、管理员评分上限及已提交代码不可篡改。
- 开赛后锁定题目与赛程、取消后禁止提交、停用账号不能访问素材；管理员可清理本范围文件。

## 浏览器验证

真实Chromium操作本地演示，包括生成并上传测试WebM、视频预览、主题整理、草稿隔离、名校编辑/发布、活动草稿/题目/发布/下一期、学生报名/提交、管理员评分、学生反馈和教师管理入口隔离。

对360、390、768、1024、1440像素视口检查三模块横向溢出；已有班级发题、作业提交、教师批阅、账号管理和CSV回归测试通过。

使用真实Supabase JS SDK和模拟HTTP，检查缺少迁移的提示、先草稿→上传→发布顺序、私有签名图片预览、上传失败保留草稿、清理及重试不重复建记录。生产构建另在 `/chatgptlearning/` 子路径验证模块加载。

## 仍需实际项目验收

当前环境没有Supabase数据库管理凭据，新迁移须由项目负责人在SQL Editor执行。真实Supabase Storage的上传/播放/下载、真实师生跨机构访问及跨设备保存，需要执行003后验收。本地模拟测试不证明远端函数、网络或套餐配额可用。

竞赛采用人工评阅，不运行代码、不自动排名；定期活动提供复制下一期草稿并由管理员审核发布。本地文件单个≤40MB，免费套餐总量以供应商Usage为准。未提交的竞赛代码没有自动草稿保存。
