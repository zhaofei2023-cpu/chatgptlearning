# 验证记录与交付边界

## 当前实例验证通过

- Vite生产构建通过，构建文件使用相对路径，适合GitHub Pages项目子目录。
- 系统Chromium浏览器：桌面首页、教师建班/发题、学生代码提交、教师评分与反馈、学生查看反馈、代码草稿本地保存、离线提示、资源搜索、学生访问教师页被界面拦截。
- 手机390px宽度：首页无横向溢出，折叠菜单与指南导航正常。
- PGlite执行SQL迁移成功，并验证注册元数据不能提权、班级访问隔离、学生不能建班或改角色、本人提交、其他学生与教师不能读取提交、教师可批阅但不能改代码、学生不能改分、截止时间限制、公开资源读取与AI每日20次原子配额。
- 数据库测试使用真正的PostgreSQL兼容执行环境；并非只检查SQL字符串。
