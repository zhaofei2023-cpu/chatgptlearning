# 四级角色与数据权限

| 能力                     | 学生                   | 教师                      | 机构管理员     | 平台管理员                 |
| ------------------------ | ---------------------- | ------------------------- | -------------- | -------------------------- |
| 新建机构及机构管理员     | 不可                   | 不可                      | 不可           | 可                         |
| 创建/停用师生账号        | 不可                   | 不可                      | 本机构         | 可选择机构                 |
| 班级和日常作业           | 加班、提交本人代码     | 创建自己的班级/作业，批阅 | 不代替教师     | 不代替教师                 |
| 主题、本地素材、名校信息 | 阅读已发布内容         | 阅读已发布内容            | 管理本机构     | 管理各机构与全平台         |
| 竞赛活动和题目           | 按规则阅读、报名、提交 | 开赛后阅读                | 管理本机构     | 管理各机构与全平台         |
| 竞赛提交与评分           | 查看本人记录/反馈      | 不读学生竞赛代码、不评分  | 评阅本机构活动 | 评阅管理范围活动           |
| 改写学生已提交代码       | 不可                   | 不可                      | 不可           | 不可（应急数据库维护另计） |

旧版教师工作台仍可分享本机构外部学习链接；第三版的文件上传、主题、名校编辑与竞赛发布只授予管理员。

新模块由数据库RLS校验发布状态、机构范围、账号启用状态及首次改密状态。平台管理员可管理全平台，机构管理员不能写入全平台或其他机构。草稿对师生不可见，主题与素材不能跨范围关联。普通角色不能改写内容所属机构或创建者。

本地文件使用 learning-materials 私有桶。上传必须与自己可管理的素材及范围匹配；师生只可读取已发布且可访问的素材。预览/下载链接最长有效1小时，撤回或停用不会收回已经下载的文件和仍有效的签名链接。硬删除会尝试清理文件；备份由平台负责人负责。

竞赛由服务器检查报名截止、报名关系与比赛时间。未开赛的题目只允许管理员读取；开赛中已报名学生及所属范围教师可阅读；结束后所属范围师生可学习题目。只有学生本人能提交代码，管理范围内的管理员可修改分数/反馈，不能修改代码。开赛后锁定题目、赛程及要求；取消后停止新提交。

帐号仍由 account-admin 服务端函数创建；service_role 不进入浏览器。公开自行注册应关闭。新账号首次改密前不开放业务数据。真实权限不能通过网页角色切换获得。

本地测试包含真实PostgreSQL规则执行及模拟Storage表的RLS验证，浏览器测试覆盖本地演示和模拟云端HTTP。实际Supabase Auth/Storage、真实账号及跨设备数据仍需项目内验收。详见 [升级与操作手册](content-management.md)。
